# VetFlu Forecast — TimesFM 2.5 (пилот)

[![ci](https://github.com/shray77/vetflu-forecast/actions/workflows/ci.yml/badge.svg)](https://github.com/shray77/vetflu-forecast/actions/workflows/ci.yml)
[![forecast](https://github.com/shray77/vetflu-forecast/actions/workflows/forecast.yml/badge.svg)](https://github.com/shray77/vetflu-forecast/actions/workflows/forecast.yml)

Пилот foundation-модели **TimesFM 2.5** (200M, Apache-2.0) для экосистемы vet-*:
недельный прогноз вспышек высокопатогенного гриппа птиц (ВПГП) по 4 флайвеям + мир
(WOAH WAHIS) + сглаженная заболеваемость по округам РФ (vet-heatmap) на GitHub
Actions (CPU, без подписок) — и **ретроспектива**: даёт ли foundation-модель
реальную пользу против простой статистики на наших рядах.

**Живая витрина:** https://shray77.github.io/vetflu-forecast/

## Состав

- `forecast.yml` — воркер: понедельник 06:00 UTC + ручной dispatch.
  WAHIS → свежий снапшот → бэктест против бейзлайнов → прогноз (+4 недели) →
  регионы vet-heatmap (бэктест + прогноз) → JSON → Pages.
- `ci.yml` — быстрые тесты (модель не нужна) + smoke-тест реальной TimesFM 2.5.
- Кэш модели: `actions/cache` → `~/.cache/huggingface` (925 МБ), ключ запинен на ревизию
  чекпоинта — воркер не качает модель каждый запуск (попадание видно в step summary job'а).
- Место в экосистеме: усиление ядра [vetflu-site](https://shray77.github.io/vetflu-site/)
  (решение Task 56 ворклога: «стоит, но узко» → пилот отдельной репой).

## Результаты ретроспективы

Первый прогон воркера: run 38411269455 (2026-10-13, runner ubuntu-latest, CPU).
Модельный кэш подтверждён: `Cache restored from key: hf-ubuntu-timesfm-2.5-200m-1d95242`
— веса (925 МБ) не скачиваются повторно ни CI, ни воркером.

**M4 Weekly** (методологическая проверка; 120 рядов, h=13, 480 пар rolling-origin + holdout):

| модель | MASE ↓ | WAPE | sMAPE |
|---|---|---|---|
| **TimesFM 2.5** | **0.368** | **3.7%** | 4.5% |
| drift (лучший бейзлайн) | 0.541 | 5.1% | 7.0% |
| naive | 0.546 | 5.2% | 7.0% |
| sma8 | 0.583 | 5.8% | 8.0% |
| snaive | 1.335 | 13.2% | 13.8% |

**Свои ряды WAHIS** (ВПГП: мир + 4 флайвея; h=4 недели, 30 пар rolling-origin):

| модель | MASE ↓ | WAPE | sMAPE |
|---|---|---|---|
| naive (лучший бейзлайн) | 0.908 | 76.9% | 88.9% |
| drift | 0.910 | 77.0% | 115.6% |
| hw (Хольт-Уинтерс) | 1.174 | 86.1% | 149.7% |
| sma8 | 1.199 | 93.7% | 99.6% |
| **TimesFM 2.5** | 0.951 | 79.0% | 151.1% |
| snaive | 1.468 | 122.1% | 109.3% |

**Регионы РФ: vet-heatmap** (Ф0 × группы болезней, сглаживание 4 нед; h=4, 27 серий, 162 пары; run 38434351444):

| модель | MASE ↓ | WAPE |
|---|---|---|
| naive (лучший бейзлайн) | **0.610** | 22.8% |
| drift | 0.615 | 23.1% |
| **TimesFM 2.5** | 0.654 | **22.9%** |
| hw (Хольт-Уинтерс) | 0.713 | 31.7% |
| sma8 | 0.790 | 30.3% |
| snaive | 1.793 | 101.2% |

**Вердикт (честный):** на типовых недельных рядах TimesFM 2.5 уверенно бьёт статистику
(MASE −32% против лучшего бейзлайна). На сырых недельных счётчиках ВПГП — **паритет
с наивной** (−4.7%, в пределах ±5%): ряд пиковый, низкочастотный, события не повторяются
по календарю неделю-в-неделю (сезонная наивная тут вообще худшая — MASE 1.47).
На сглаженной региональной заболеваемости РФ — **no_value**: наивная лучше на 7.1%
по MASE (по WAPE TimesFM на уровне лучшего — 22.9% против 22.8%), ряды короткие
(~200 недель, из них плотная эра ~150) и без выраженной годовой сезонности —
именно там, где статистика ещё сильна.
Практический вывод: foundation-модель имеет смысл применять не к сырым счётчикам
событий и не к коротким рядам без сезонной структуры, а к длинным сезонным рядам
(M4-подобным); слой прогноза на vet-heatmap публикуется как ориентировочный
(опциональный тоггл + вердикт в легенде), а не как инструмент принятия решений.
Точная цифра прогноза на текущую неделю — на витрине.

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python -m vetflu_forecast.cli all          # бэктест + прогноз -> site/data/*.json
python -m pytest -m "not slow"             # быстрые тесты
python -m pytest -m slow                   # smoke реальной модели
```

## Данные и методика ретроспективы

- **Свои ряды**: недельные счётчики событий ВПГП из WOAH WAHIS (мир + 4 флайвея,
  веса стран как в vetflu-site: primary 1.0 / adjacent 0.4). Rolling-origin, h=4 недели.
- **Регионы РФ**: outbreaks.json vet-heatmap (обновляется каждые 6 ч) → недельные
  ряды «округ × группа болезней» + национальные, скользящее среднее 4 нед, серии
  с ≥24 событиями с 2023 г.; центроиды округов из координат событий. Rolling-origin,
  h=4 недели. Прогноз → `forecast_regions.json` (point/q10/q90 + история + вердикт).
- **Методологическая проверка**: M4 Weekly (вендорено в `data/`, выборка 120 из 359
  рядов, сид 42), h=13, включая holdout на M4-test.
- **Модели-соперники**: naive, сезонная наивная (m=52), drift, SMA(8), Хольт-Уинтерс
  (на своих рядах) против TimesFM 2.5.
- **Метрика**: сезонный MASE (масштаб по контексту), WAPE, sMAPE, RMSE.

## A/B: Chronos-2 и Toto 2.0 против TimesFM 2.5 (2026-10)

Эксперимент `scripts/ab_run.py` + сводка `scripts/ab_merge.py`: те же пары
rolling-origin, те же метрики, сравнение с published-цифрами воркера
(M4 0.368 / WAHIS 0.9505 / regions 0.654). Модели — Apache-2.0:
Chronos-2 (amazon/chronos-2, 120M) и Toto-2.0-4m (Datadog, 4M ≈ 16 МБ).
Point-прогноз — медиана q50 у всех (у Chronos-2 21 квантиль, индекс ищется по уровням).

| Панель | naive/лучший бейзлайн | TimesFM 2.5* | Chronos-2 | Toto-4m |
|---|---|---|---|---|
| M4 Weekly (h=13) | drift 0.541 | 0.368 | **0.359** | 0.379 |
| WAHIS сырые (h=4) | naive 0.908 | 0.951 | 0.934 | **0.877** |
| Регионы РФ (h=4) | naive 0.610 | 0.654 | 0.671 | 0.660 |
| Метео t/THI (h=4, эксперимент) | snaive 0.914 | **0.673** | 0.695 | 0.698 |

\* published-прогон воркера (та же детерминированная схема; бейзлайны воспроизведены
локально до 4-го знака). Выводы: (1) все три foundation-модели в пределах ±3% друг
от друга — рабочая TimesFM 2.5 не уступает новичкам, смена не оправдана; (2) Toto-4m
единственный чуть обогнал naive на сырых событиях (+3.4%, в зоне паритета ±5%);
(3) вердикт regions no_value подтверждён всеми тремя — слой на хитмапе остаётся
опциональным; (4) на погоде все бьют сезонную наивную на ~24–26% («умная климатология»),
но для прод-решений погода остаётся справкой, не прогнозом.

## Метео-данные эксперимента

`vetflu_forecast/data_meteo.py`: дневные t/RH по центроидам флайвеев (path/paths из
`data/migration.json` vetflu-site), источник — NASA POWER (MERRA-2, без ключа;
Open-Meteo archive — фолбэк, у него дневная квота на IP). Недельные средние W-SUN +
THI (NRC/Thom) по недельным средним — приближение: прод-THI в vet-meteo считается
по часовым данным, здесь THI только для сопоставимости рядов.
